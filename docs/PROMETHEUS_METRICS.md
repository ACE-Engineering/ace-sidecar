# Prometheus Metrics & Telemetry Exporter Guide

The ACE Sidecar exposes a native Prometheus exporter endpoint at `http://127.0.0.1:8787/metrics` serving metrics in standard **Prometheus Text Exposition Format (v0.0.4)**.

This endpoint is intended for machine-to-machine time-series collection, enabling cluster SREs, DevOps engineers, and developers to scrape metrics into **Prometheus**, **Grafana Alloy**, **VictoriaMetrics**, **OpenTelemetry Collector (OTel)**, **Datadog**, **Snowflake**, or **ClickHouse**.

---

## 📊 Emitted Metrics Reference

| Metric Name | Type | Labels | Description |
| :--- | :--- | :--- | :--- |
| `ace_sessions_total` | Counter | `agent` | Total observed developer session transcripts (`all`, `claude`, `antigravity`). |
| `ace_turns_total` | Counter | `agent` | Total AI agent API turns / model invocations. |
| `ace_tokens_input_fresh_total` | Counter | — | Uncached prompt input tokens. |
| `ace_tokens_cache_read_total` | Counter | — | Prompt input tokens served directly from Anthropic prompt cache. |
| `ace_tokens_cache_write_total` | Counter | — | Tokens written to Anthropic prompt cache. |
| `ace_tokens_output_total` | Counter | — | Completion output tokens generated by the model. |
| `ace_cost_usd_total` | Counter | `agent` | Cumulative list-price cost valuation in USD. |
| `ace_peak_context_tokens` | Gauge | — | Maximum context window depth observed in a single turn. |
| `ace_cache_read_share` | Gauge | — | Ratio of prompt input tokens served from prompt cache (`0.0` to `1.0`). |
| `ace_session_time_seconds` | Counter | `state` | Cumulative session time in seconds (`wall_clock`, `active`, `idle`, `parked`). |
| `ace_model_requests_total` | Counter | `model` | Total requests processed by model (e.g. `claude-sonnet-5`, `gemini-3.6-flash`). |
| `ace_model_prompt_tokens_total`| Counter | `model` | Prompt tokens by model. |
| `ace_model_output_tokens_total`| Counter | `model` | Output tokens by model. |
| `ace_model_cost_usd_total` | Counter | `model` | Cost in USD by model. |
| `ace_tool_bytes` | Gauge | `type` | Tool declaration payload size in bytes (`total`, `unused`). |
| `ace_installed_skills_total` | Gauge | — | Number of active workflow skills installed on disk. |

## ⚙️ Scraping Setup

### 1. Prometheus Server (`prometheus.yml`)

Add the sidecar scrape job to your Prometheus configuration:

```yaml
scrape_configs:
  - job_name: 'ace_sidecar'
    scrape_interval: 15s
    static_configs:
      - targets: ['127.0.0.1:8787']
```

### 2. OpenTelemetry Collector (`otel-collector-config.yaml`)

```yaml
receivers:
  prometheus:
    config:
      scrape_configs:
        - job_name: 'ace_sidecar'
          scrape_interval: 15s
          static_configs:
            - targets: ['127.0.0.1:8787']

exporters:
  datadog:
    api:
      key: "${DATADOG_API_KEY}"

service:
  pipelines:
    metrics:
      receivers: [prometheus]
      exporters: [datadog]
```

## 🔍 Sample PromQL Queries

* **Request Rate (RPS)**:
  ```promql
  rate(ace_turns_total[5m])
  ```
* **Cache Read Hit Ratio**:
  ```promql
  ace_tokens_cache_read_total / (ace_tokens_input_fresh_total + ace_tokens_cache_read_total + ace_tokens_cache_write_total)
  ```
* **Cost Acceleration per Model (USD/hr)**:
  ```promql
  rate(ace_model_cost_usd_total[1h]) * 3600
  ```

## 💻 Visual Web Dashboard & Machine APIs

* **Interactive Developer Dashboard**: Navigating to `http://127.0.0.1:8787/dashboard` provides rich visual charts, glassmorphic scorecards, and a built-in **Prometheus & Data Export Drawer**.
